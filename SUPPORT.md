# Questions and support

Use this repository's [GitHub issues](https://github.com/birdayz/fdb-go/issues)
for usage questions, reproducible bugs, and feature requests. Search existing
issues first. For contributions, see [CONTRIBUTING.md](CONTRIBUTING.md).

This is a community project. Filing an issue does not establish a response-time,
fix, or production-support commitment. Check the [README](README.md) and
[STATUS.md](STATUS.md) for project status and limitations before adopting it.

## Useful report details

Include the commit or version, operating system and architecture, FoundationDB
version, client backend, and a minimal reproduction. For SQL bugs, include the
schema, sample data, query, expected result, and actual result. For CLI/Docker
problems, include the command, Docker version/context type, and whether the client
runs on the host or in a container. Remove credentials, private data, and sensitive
network details from logs and examples before posting.

## Security

Do not post an unfixed vulnerability or its exploit details in a public issue.
Follow [SECURITY.md](SECURITY.md) for security reporting guidance.
