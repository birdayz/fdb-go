# Provisioning

Mounted at `/etc/grafana/provisioning` by `docker-compose.yaml`
(see [Provision dashboards and data sources](https://grafana.com/tutorials/provision-dashboards-and-data-sources/)).

- `datasources/datasources.yml`: one FoundationDB datasource (`uid: fdb-dev`) on
  the compose stack's FDB (`docker:docker@fdb:4500`, a hostname coordinator),
  database `/OTEL/R_GRAFANA_DEV`, tenants `T*`, default `T0`.
- `dashboards/`: the R1 load dashboard `fdb-load` (20 panels, 5 s refresh),
  generated by `tests/load/gen-dashboard.mjs` from `tests/load/panels.mjs`.

The compose stack's `seed` job writes `/OTEL/R_GRAFANA_DEV` through
`otel.Exporter` (`cmd/seed`): T0 with GenAI messages as deltas, T1 with
full-text messages, `SEED_TRACES` traces each (default 200) over the last 6 hours.
