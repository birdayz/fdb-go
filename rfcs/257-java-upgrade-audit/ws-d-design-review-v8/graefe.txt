## P2 — The peel bound rests on the wrong axis; many isolated outliers still strand (design 890-898, 927-933)

**The claim.** The bound is "logarithmic because the slowest measured pattern at least halves M per round." That is true only of the 60/40 shape.

**What the outlier rows show.** Every outlier row removes one member of M per round:
- `[999 1]I>999[999 1]I>998…` in `evidence-run.txt:189,191`;
- nested: 999 → 997 at `:190`.

The refit isolates one far point, the peeled point rejoins the core by nearest centroid, and the next outlier is isolated. So the number of rounds follows the number of separately isolatable outliers, not log n.

**Why the measurements don't catch this.** Every measured shape has at most 3 outliers, and all are 2-D (`tightGrid`). In high-dimensional embeddings, far outliers are nearly orthogonal to each other, so each one gets isolated on its own.

**The fallthrough is therefore ordinary data.** At n = 1000 the bound is 12 refits, so any cluster with ≥ 13 such outliers (about 1.3%) goes to the reconcile. The reconcile clears the flag but never splits the cluster:
- **Deferred mode:** it strands at the cap as the target does, and the hand-off ends with the typed capacity error.
- **Inline mode:** each re-armed split runs up to 13 extra KMeans fits plus a serializable read of the whole posting inside a user's insert, until the count passes hardMax and the partition wedges.

For this population, (h) only delays the stall the README (item 3) says it removes.

**Mutation evidence.** The v8 mutation `bound=12→11` kills a golden string only. No measured shape reaches the bound.

**Needed:**
- Measure m ∈ {13, 20, 50} isolated outliers at n = 1000 in realistic dimension.
- Then decide: either a peel whose round count does not scale with m (keeping the nearest-centroid and minChildFraction invariants), or declare this population and its consequence under (h).
- Measure the peel plus reconcile at n = 2000 in high dimension against the 5 s transaction limit, because inline mode pays it inside user inserts.
