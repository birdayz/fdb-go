**[P1] A range clear can be followed by publication of an older, previously unattached state snapshot.**

[clearRangeWithIndexStateViews at index_state.go:312](/home/birdy/projects/fdb-go/pkg/recordlayer/index_state.go:312) protects only views already registered. However, [loadStoreState at store.go:1921](/home/birdy/projects/fdb-go/pkg/recordlayer/store.go:1921) populates a handle’s local map without registering its view. An ordinary `Open()` with unchanged metadata can return in that condition. Later, [ensureStoreStateLoaded at store.go:178](/home/birdy/projects/fdb-go/pkg/recordlayer/store.go:178) registers that previously loaded map without checking whether a clear intervened.

A sequential reproduction follows directly:

1. Start with a nonempty store and index `I` DISABLED, with its index data empty.
2. In a fresh context, `Open()` the store using unchanged metadata. Do not call a state getter.
3. Call `ctx.ClearRange(store.IndexStateSubspace())`. The persisted state key disappears, but no view is registered, so the clear updates no projection.
4. Call `store.MarkIndexDisabled("I")`. Initialization publishes the pre-clear DISABLED snapshot. The [unchanged-state return at index_state.go:254](/home/birdy/projects/fdb-go/pkg/recordlayer/index_state.go:254) skips the required write.
5. Commit and cold reopen: the absent state key means READABLE, although the index remains empty and records remain present.

This uses the context clear API, requires no concurrency or direct transaction mutation, and defeats the caller’s explicit request to restore DISABLED. An in-flight lazy load can encounter the same publication problem across a clear.

**Required correction:** coordinate initial state loading/publication with range clearing, including snapshots loaded before registration. Merely locking registration after loading cannot establish freshness. Add a real-FDB regression for the sequence above and a deterministic load-versus-clear interleaving; assert raw bytes, shared state, committed DISABLED state, and cold-open scan rejection.
