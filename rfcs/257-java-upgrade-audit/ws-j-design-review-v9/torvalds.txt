## MEDIUM

**1. The edited-file route skips the evolution validator (design :1865-1885, (p) :2158-2161).**
- A normal save loads the old metadata and runs `s.evolutionValidator.Validate(oldMeta, newMeta)` (`metadata_store.go`, `SaveRecordMetaData`).
- `SaveMigratedLegacyMetaData` cannot load the old side, so v9 admits an edited file on its framing alone: same full name at the same union field number, it loads, and its version is the stored one plus 1. The design calls that "the whole requirement" (:1877). It is not. The route would admit all of these:
  - a changed primary key;
  - an index root changed with no `last_modified_version` bump (no rebuild on open, so reads through that index return wrong rows);
  - an index dropped without a FormerIndex;
  - renumbered or retyped fields inside a framed message;
  - a change to `split_long_records` or `store_record_versions`.
- **Fix:**
  - Load the stored bytes under `union` (an internal loader that names that union and skips (d); for UnionDescriptor, use the replay's framing).
  - Validate old → edited with `MetaDataEvolutionValidator`.
  - Pin two refusals: an index root edited with no version bump, and a framed field retyped.

**2. The restore's "nothing binds (t, v)" check is not atomic (:491, :531-536).**
- The listing runs in batch transactions. The final transaction re-checks only that (t, v) is not stored, and its conflict range covers only writes after its own read version.
- The design justifies that window with "a DROP SCHEMA there only shrinks the set". That holds for the header check, but not for the new refusal, which fires exactly when the set shrinks to empty.
- **Sequence:**
  1. The restore lists S, the only schema bound to (t, 3).
  2. DROP SCHEMA S.
  3. A fresh CREATE SCHEMA TEMPLATE t is admitted, since nothing binds t any more.
  4. The restore commits (t, 3) from the old history.
- That is the two-history state of Torvalds v8 #2 again, reached by a race.
- **Fix:** in the final transaction, read the (t, v) bindings with limit 1 (O(1)) and refuse if there are none. Also add a conflict range over t's template rows. Pin it with an FDB interleaving test.
