**1. Medium-low: false Java claim behind a declared divergence (from reading source).**
- Three places say Java's indexer does not reconcile on open:
  - `DIVERGENCES.md:2739-2740`
  - `online_indexer_queue.go:67-68`
  - `ws-c-design.md:480`
- Java's indexer does reconcile:
  - it opens the store with `copyBuilder().setContext(context).openAsync()` (`IndexingBase.java:129-130`);
  - that calls `createOrOpenAsync`, then `checkVersion` (`FDBRecordStore.java:6015`), then `checkPossiblyRebuild` (`:2689`);

- None of the three v2 reviewers caught this. It is the same kind of problem as v1's `ifMismatchPrevious` finding: a false statement about Java used to justify a difference.
