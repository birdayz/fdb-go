1. **P1 — Queued replay can hit backpressure before reaching the merger that would relieve it.**  
   The [integration specification](/home/birdy/projects/fdb-go/rfcs/257-java-upgrade-audit/ws-d-research/maintenance-integration.txt:20) preserves complete queue drain before requested merges. That is the actual ordering in [online_indexer.go](/home/birdy/projects/fdb-go/pkg/recordlayer/online_indexer.go:903). Queue replay merely accumulates merge requests after successful commits; its [retry loop](/home/birdy/projects/fdb-go/pkg/recordlayer/throttled_retrying_iterator.go:85) retries failures without consuming those requests. With deferred maintenance and enough queued inserts into one cluster, replay reaches the hard cap, repeatedly retries the blocked entry, and eventually returns before maintenance runs. The [acceptance matrix](/home/birdy/projects/fdb-go/rfcs/257-java-upgrade-audit/ws-d-design.md:243) tests backpressure and queued completion separately, missing their interaction. Specify maintenance between committed replay batches and typed-cap recovery outside the failed transaction, preserving queue position and session ownership. Require a queued build exceeding the cap that completes through actual claim/drain/retry work.

2. **P1 — “Attempt-local” caches do not establish isolation or synchronization.**  
   The [retained maintainer boundary](/home/birdy/projects/fdb-go/rfcs/257-java-upgrade-audit/ws-d-design.md:31) leaves both unspecified. Current [partition storage caching](/home/birdy/projects/fdb-go/pkg/recordlayer/vector_index_maintainer.go:270) shares mutable maps across operations; [node cache hits](/home/birdy/projects/fdb-go/pkg/recordlayer/hnsw.go:1856) bypass the supplied transaction entirely. A snapshot search followed by a serializable search/write can therefore reuse nodes without installing their read conflicts. Concurrent neighbor changes need not modify access information. Separately, different-prefix write locks do not protect the shared cache registry, and searches also populate it. Specify cache read-provenance rules or operation-local caches, registry synchronization, and matching scan/write/delete ownership. Require snapshot-then-write conflict tests and concurrent grouped scan/write/clear race cases.

3. **P1 — Admission checks cover codec availability but omit other delayed configuration failures.**  
   The [admission contract](/home/birdy/projects/fdb-go/rfcs/257-java-upgrade-audit/ws-d-design.md:41) promises mutation-free configuration rejection, but Java’s [GuardiANN Config constructor](/home/birdy/projects/fdb-go/fdb-record-layer/fdb-extensions/src/main/java/com/apple/foundationdb/async/guardiann/Config.java:196) accepts configurations its maintenance dependencies cannot execute. For example, `EUCLIDEAN_SQUARE_METRIC` reaches [KMeans’ unsupported-metric branch](/home/birdy/projects/fdb-go/fdb-record-layer/fdb-extensions/src/main/java/com/apple/foundationdb/kmeans/KMeans.java:652); zero iterations fails its earlier validation. Ordinary inserts can already have persisted records and tasks before either failure. Freeze an engine capability admission policy covering these dependencies, with explicit Java divergence and mutation-free acceptance tests. Also scope the [“config accepts bits 1–15” statement](/home/birdy/projects/fdb-go/rfcs/257-java-upgrade-audit/ws-d-design.md:61) to HNSW: GuardiANN’s constructor does not impose that range.

However, “handle at the narrow boundary” leaves substantive decisions until implementation. For example, [primary deletion passes zero underreplicated delta](/home/birdy/projects/fdb-go/fdb-record-layer/fdb-extensions/src/main/java/com/apple/foundationdb/async/guardiann/Primitives.java:1305), while [collapsed deletion derives its membership signature from transformed input](/home/birdy/projects/fdb-go/fdb-record-layer/fdb-extensions/src/main/java/com/apple/foundationdb/async/guardiann/Delete.java:226). Define the required Go invariant, conditional corrective behavior, stored-byte compatibility boundary, and distinguishing JVM/Go assertions for each hypothesis before granting the design gate. This requests a concrete contract, not execution during this read-only review.
