## MEDIUM
**M-1. A false fact about Java.** 9 (s) (`:2683`), section 2 (`:694`), `DIVERGENCES.md:2910` and `fdb_template_catalog.go:277` call `DeleteTemplateVersion` Go-only.
- Java has the same API: `SchemaTemplateCatalog.java:112`, implemented at `RecordLayerStoreSchemaTemplateCatalog.java:317-325`. It deletes a bound version without checking bindings.
- So Java writers can leave dangling bindings below the latest version. The landed guard reads only from latest+1.
- As a result, a library `CreateTemplate(t, v)` with v below the latest silently re-issues a bound version that Java deleted. SQL and `fleet.SaveTemplate` are protected by the save action's `v′ <= latest` refusal.
- Step 3 moves that refusal into `CreateTemplate`, so the guard depends on it. The design should say so, and a test should pin this case.
