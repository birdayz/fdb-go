## MEDIUM
**2. Shape (g) compares the wrong field numbers (`:2335-2338`).**
- Today's implicit record-type key is the SMALLEST union field number (Java `RecordType.java:171-180`, Go `metadata.go:417-418`). The preferred field the design cites (`:420-423`) only decides which field a write uses.
- Pre-upgrade Go keyed by the LAST declared field (`e48f5b496:metadata.go:330-358`, `:1837`).
- Example `{T a=1; T b=2;}`: pre-upgrade key 2, today key 1. The design compares 2 with the preferred field's 2 and loads it, so rows are silently re-keyed.
- Example `{T _T=2; T b=1;}`: the keys agree, but the design refuses it.
- **Fix:** compare the last declared number with the minimum.
