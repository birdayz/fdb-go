## HIGH
**1. The restore's two-history check is too narrow (design :618-626).**
- It compares only record-type keys and union numbers.
- The design's own hazard (:555-559) is a foreign version that "differs only in a predicate, with matching index versions". That passes this check.
- Restore (t,3) beside a fresh v1 with the same tables. Latest becomes 3. A schema bound to v1 is then repaired onto v3. The rebind validator admits the predicate change, and the sparse index is misread silently.
- **Fix:** compare the carry rule's index invariants per name (subspace key, added version, and at equal last-modified versions the compared fields including the predicate) plus FormerIndexes. Add that case to the tests.

## MEDIUM
**2. Step (ii) of the edited-file route does not use step (i)'s framing (:2113-2120 vs :2137-2141).**
- `unionCorrespondence` pairs union fields by their declared TYPE and refuses any non-message union field (`metadata_evolution_validator.go:318-322`).
- The name-first framing step (i) adopts is exactly where name and type disagree. The pre-upgrade writer framed records by field NUMBER with a raw BytesType tag (`e48f5b496:store.go:2072`).
- The pinned (d) shape "a UnionDescriptor with a scalar `_T`" (`metadata_validate_records_test.go:434`) is therefore refused as "field in union is not a message type". So are the non-message fields step (i) deliberately suspends. None of these edits can pass, so ":2093 the way out of every shape" is false.
- A `_X` field whose type is Y is compared as Y.
- **Fix:** pair from the loaded record types' union fields, not the old union's field types, or declare these shapes routeless. Test the scalar `_T` shape.

**3. R1's bound is false for predicates and the record count key (:2157-2160).**
- Neither Go's `Build` nor Java's `MetaDataValidator` validates index predicates or the record count key against descriptors.
- `resolveFieldPath` returns "unset" for a missing field (`index_predicate.go:303-311`).
- So a predicate through a removed holder silently changes the sparse index's membership, with no rebuild.
- **Fix:** add an explicit R1 check over predicate paths and the count key, and test both.

**4. R2 cannot pass under the store's default validator (:2137, :2161-2166).**
- `DefaultMetaDataEvolutionValidator` has `allowIndexRebuilds=false` (`:72`; `metadata_store.go:32`).
- The CHANGED index R2 requires is refused as "last modified version of index changed" (`:689-690`).
- The planned test "R2 admitted with the index CHANGED" fails as specified.
- **Fix:** state the option the route sets, or add it as a third relaxation scoped to R2's indexes.

**5. The in-memory lock-order premise is false (:966-970).**
- `SaveSchema` checks the template before taking `c.mu` (`store_catalog.go:86-101`).
- `RepairSchema` releases `c.mu` before `LoadSchemaTemplate` (`:142-147`).
- No existing path holds both mutexes, and SaveSchema's check-then-bind is not atomic against the new guarded `DeleteTemplateVersion`.
- **Fix:** specify that both methods hold `c.mu` across their template reads, and add a `-race` interleaving test.
