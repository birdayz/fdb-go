## MEDIUM
1. **R1's reach bound is false for two of the four readers it names** (`:2157-2160`; v10 Torvalds #3 is still open).
   - `Build` validates only primary keys and index roots (`metadata.go:834`, `:849`; Java's `MetaDataValidator.java:96`, `:118`).
   - Predicates resolve their fields only when evaluated, and read a missing field as unset (`index_predicate.go:303-312`).
   - Neither validator reads the record count key.
   - So removing a holding field that a predicate or the count key reads through still loads, and silently changes index membership or count grouping.
   - **Fix:** refuse R1 in both cases, and test both.

2. **The restore's two-history check compares only record-type keys and union numbers** (`:622-626`).
   - The hazard the design itself names, an index difference in predicate only with matching versions (`:556-559`), passes that check.
   - So do differing index subspace keys and definitions, and FormerIndexes.
   - **Fix:** compare indexes by name (subspace key, and EQUIVALENT or a later last-modified version) and FormerIndex keys; test the predicate-only case.

3. **"The save action calls `CreateTemplate` and nothing else"** (`:959`, `:1537`) leaves two checks unplaced.
   - `Execute` today refuses `v′ <= latest` and runs the relational validator (`save_schema_template.go:33-44`).
   - Section 2 (`:493-494`) and section 4's "latest suffices" argument (`:1617-1620`) depend on both.
   - A direct `CreateTemplate(t, v′ < latest)` is refused only as an exact duplicate (`template_catalog.go:99-101`), and the guard reads from latest + 1. So a version carried from the latest can be stored below it.
   - **Fix:** run both checks inside `CreateTemplate`, and add them to the write-path table.

4. **The edited-file route's framing does not survive step (ii).**
   - The validator pairs union fields by each field's own message type and builds its renames from those pairs (`metadata_evolution_validator.go:238-243`, `:331`).
   - It also refuses any old union field that is not a message (`:321-323`).
   - So step (i)'s name-first framing is overridden exactly where it differs from type-first:
     - a scalar `_T`, whose rule step (i) "suspends", is refused again;
     - a `_X` field of type Y becomes "record type X removed" (`:347-353`).
   - So `:2139-2141` overclaims, and the test at `:2182-2183` either cannot tell the framings apart or fails.
   - The direction rule (`:2113-2118`) is undefined for shape (b), and for the case where both choices are the same message (for example (c) in a usage=UNION file).
   - The envelope tests "R1 … without it refused" (`:2184-2186`) contradict `:2142-2145`: the validator never compares an envelope.

5. **Section 9 (p) still states v10's route** (`:2480-2484`). It says `SaveMigratedLegacyMetaData` admits edited files, "relaxed only for the holding fields of type UnionDescriptor". That is two specs again, which is what v10 asked to remove.

6. **The lane check over WIDENED contradicts (m)** (`:1003-1009`, `:1531-1534`, `:2467-2474`).
   - Real tenants holding the eight lane-less shapes were stored by pre-F2 builds, with `long_value` literals (`:1666-1667`).
   - A hand-built version at this build's width is therefore WIDENED (`:846-849`), still has no lane, and is refused.
   - So "carries it as EQUIVALENT and is admitted" (`:1008`, `:2472`) and the pin at `:1011-1014` hold only if the builder repeats `long_value`.
   - **Fix:** scope the claim to that case, or exempt a WIDENED key whose widened form still has no lane.
